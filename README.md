# fast_food App

A modern, responsive Fast Food Ordering Mobile Application built using React Native & Expo.
This app delivers a smooth and intuitive user experience with authentication, dynamic cart management, and customizable menu options.

## Overview

This project showcases a complete food ordering flow:

1. User authentication
2. Browsing menu items
3. Customizing orders
4. Managing cart state
5. Viewing and editing profile

It is designed with clean architecture, reusable components, and scalable state management.

## Tech Stack

- React Native
- Expo
- React
- NativeWind (Tailwind CSS for React Native)
- Appwrite (Backend & Database)
- TypeScript
- Zustand (State Management)
- Custom Hooks
- Async Storage

## Project Setup

### 1️⃣ Clone the repository

```bash
git clone <https://github.com/Altamash-khn/fast_food.git>
```

### 2️⃣ Install dependencies

```bash
npm install
```

### 3️⃣ Environment Variables

Create a `.env` file and add your credentials:

```env
EXPO_PUBLIC_MOVIE_API_KEY=YOUR_API_KEY
EXPO_PUBLIC_APPWRITE_PROJECT_ID=YOUR_API_KEY
EXPO_PUBLIC_APPWRITE_DATABASE_ID=YOUR_API_KEY
EXPO_PUBLIC_APPWRITE_BUCKET_ID=YOUR_API_KEY
EXPO_PUBLIC_APPWRITE_ENDPOINT=YOUR_API_KEY
EXPO_PUBLIC_APPWRITE_COLLECTION_ID=YOUR_API_KEY
EXPO_PUBLIC_APPWRITE_CATEGORIES_COLLECTION_ID=YOUR_API_KEY
EXPO_PUBLIC_APPWRITE_MENU_COLLECTION_ID=YOUR_API_KEY
EXPO_PUBLIC_APPWRITE_CUSTOMIZATION_COLLECTION_ID=YOUR_API_KEY
EXPO_PUBLIC_APPWRITE_MENU_CUSTOMIZATION_COLLECTION_ID=YOUR_API_KEY
EXPO_PUBLIC_APPWRITE_IMAGE_STORAGE_BUCKET_ID=YOUR_API_KEY
```

> ⚠️ Make sure to replace these values with your **own keys**.
